# TIAGo — Autonomous Mobile Manipulation and HRI

Public overview of a collaborative ROS 2 mobile manipulation project for the HRAI course at Sapienza University of Rome.

## Technical focus

- Open-vocabulary 3D perception and VLM-based task planning
- SLAM-based mapping, Nav2 autonomous navigation, and grasping
- Multimodal human–robot interaction in Gazebo/Ignition simulation

The project source repository is private. This overview contains no project code or restricted material.
